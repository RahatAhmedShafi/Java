💡 High Score Tips

1. Floating Point Compares Avoid == for comparing double/float values. Use tolerance limits: Math.abs(a - b) < 1e-5.
2. Constructor Return Types A constructor must not have a return type, not even void. Placing a return type makes it a standard method!
3. Static Restrictions Static contexts (like static methods) cannot access non-static fields (like this.x) directly without instantiating an object first.
4. Subclass Constructor Chain A subclass constructor calls its superclass constructor implicitly (via default constructor call) unless you invoke super(...) explicitly.

📘 Classes, Objects, and Variables

When an object is declared, memory is not occupied. Instantiation allocates memory on Heap.

Direct Access Style (UIU Preferred Midterm Style)

In direct access style, class fields do not have access modifiers like private or public. You manipulate them directly:

class Point {
    int x;
    int y;
    
    Point(int x, int y) {
        this.x = x; // Resolves local parameter shadowing
        this.y = y;
    }
}

🧬 Static vs. Instance Members

  • Instance Variables: Individual copies for each object. Allocated during instantiation.
  • Static Variables: Single copy shared by all instances of the class. Loaded once, accessible via class name.
class Counter {
    int count = 0;
    static int staticCount = 0;
    
    Counter() {
        count++;        // Changes only local instance variable
        staticCount++;  // Changes shared static variable across all objects
    }
}

📐 Composition & Containment (Geometric Math)

Composition nests an object within another class. Let's study how shape overlapping/containment is coded:

1. Circle inside Circle

For Circle A to reside entirely inside Circle B, the distance between their center points plus A's radius must be less than or equal to B's radius.

boolean circleInsideCircle(Circle C) {
    double centerDist = this.center.distance(C.center);
    return (centerDist + C.radius) <= this.radius;
}

2. Circle inside Rectangle

Calculate the bounding limits of the circle (left, right, bottom, top) and check if they fit inside the Rectangle's bottomLeft and topRight boundaries.

boolean circleInsideRectangle(Circle C) {
    double left = C.center.x - C.radius;
    double right = C.center.x + C.radius;
    double bottom = C.center.y - C.radius;
    double top = C.center.y + C.radius;
    
    return left >= this.bottomLeft.x && 
           right <= this.topRight.x && 
           bottom >= this.bottomLeft.y && 
           top <= this.topRight.y;
}

🐾 Inheritance & Polymorphism

Constructor Chaining

Subclass constructors must invoke super(...) first. If not done explicitly, Java automatically places a call to super() (no-args constructor).

Downcasting & Polymorphism

A reference variable of type Parent can refer to a Child object. To use specific child methods, downcast explicitly:

FoodItem x = new Fish("Hilsha");
((Fish) x).setparameter(); // Downcasting syntax

Q1: Traders & Asset Validation Scenario (Midterm Design Question)

Create an Asset class representing Stock/Bonds, allocating unique serial IDs via a static counter. Create a Trader class that registers traders and executes automated matching logic matching asset categories with departmental allocations.

Java Implementation:

class Asset {
    String assetType;
    private float price;
    int id;
    static int id_counter = 1001;

    Asset(String assetType, float price) {
        if(assetType.equals("Bond") || assetType.equals("Stock"))
            this.assetType = assetType;
        setPrice(price);
        id = id_counter;
        id_counter++;
    }

    public void setPrice(float price) {
        if(price >= 0)
            this.price = price;
    }
    
    public float getPrice() { return this.price; }
}

class Trader {
    String name;
    String department = "Bond";
    float aum = 0.0f;

    Trader(String name, String department) {
        this.name = name;
        this.department = department;
    }
    
    Trader(String name) {
        this.name = name;
    }

    public void assign(Asset asset) {
        if(asset.assetType != null && asset.assetType.equals(this.department)) {
            aum += asset.getPrice();
        } else {
            System.out.println("Department Mismatch");
        }
    }
}

Key Takeaways:

Encapsulated variables (like price) must be updated inside the constructor using the corresponding mutator method (setPrice(price)) so that validation is not bypassed.

Q2: Point2D & Point3D Coordinate Extension (Spring 24 Q1)

Implement simple inheritance demonstrating construction chaining, coordinate mapping, and display overrides using super calls. 

class Point2D {
    int x, y;
    
    public Point2D(int x, int y) {
        this.x = x;
        this.y = y;
        System.out.println("Point2D constructor");
    }
    
    public String Display() {
        return "x = " + x + ", y = " + y;
    }
}

class Point3D extends Point2D {
    int z;
    
    Point3D(int x, int y, int z) {
        super(x, y); // Explicit parent call
        this.z = z;
        System.out.println("Point3D constructor");
    }
    
    public String Display() {
        return super.Display() + ", z = " + z;
    }
}

public class Myparent {
    private int p;
    
    public final int myfunction() {
        return p * p;
    }
    
    public Myparent(int Q) { this.p = Q; }
    public Myparent() { this.p = 0; }

}

public class Mychild extends Myparent {
    public Mychild(int K) { super(K); }
    public Mychild() { super(0); }

Q4: Polymorphism & Downcasting with FoodItem Arrays (Spring 24 Q4)

Create base FoodItem references mapping subclasses (e.g. Fish, Vegetable), setting specific child parameters through safe explicit downcasting. 

public class MyTest {
    public static void main(String[] args) {
        FoodItem x[] = new FoodItem[2];
        x[0] = new Fish("small");
        x[1] = new Vegetable("Cauliflower");
        
        // Specific child methods executed via explicit downcasting
        ((Fish) x[0]).setparameter();
        ((Vegetable) x[1]).setparameter();
        
        double p = 0;
        double amount[] = {3, 2};
        for(int i = 0; i < x.length; i++) {
            p += x[i].getprice(amount[i]);
        }
        System.out.println("price = " + p);
    }
}

⚡ Flip Study Flashcards

Instantiation
Creating a concrete instance of a class in the heap memory using the new keyword.
Shadowing
When a local variable or parameter has the same name as a field. Resolved using this.fieldName.
Static Variable
A class-level variable shared by all objects. Initialized once when the class is loaded.
Instance Variable
An object-level variable. Each object gets its own separate copy initialized on the heap.
Composition
A design relationship where one class contains reference variables of another class (e.g., Circle has a Point center).
Downcasting
Casting a general parent reference back into a specific subclass type to call its specific, non-overridden methods.
