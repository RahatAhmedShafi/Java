Q4: ColorPrinter and Overloading Overrides

Provide overloaded printing methods in a base class and override them in a child class using super calls.

SolutionJava Code:

class Printer {
    private String brand;
    public Printer(String brand) { this.brand = brand; }
    
    public void print(String doc) {
        System.out.println("Printing document: " + doc);
    }

    // Overloaded print method
    public void print(String doc, int copies) {
        System.out.println("Printing " + copies + " copies of the document: " + doc);
        for (int i = 1; i <= copies; i++) {
            System.out.println("Printing copy " + i);
        }
    }
}

class ColorPrinter extends Printer {
    private String color;
    public ColorPrinter(String brand, String color) {
        super(brand);
        this.color = color;
    }

    // Overridden print method
    public void print(String doc) {
        super.print(doc);
        System.out.println(this.color + " Color mode enabled");
    }
}

static void printTotalArea(Shape[] shapesArray) {
    double totalArea = 0;
    for (Shape s : shapesArray) {
        if (s instanceof Rectangle) {
            totalArea += ((Rectangle) s).getArea();
        }
    }

Q1: Asset & Trader Financial System

Design class assets and traders processing validation, pricing mutations, automated unique IDs, and matching allocations.

SolutionJava Code:

class Asset {
    String assetType;
    private float price;
    int id;
    String tradersName = "";
    static int id_counter = 1001;

    Asset(String assetType, float price) {
        if(assetType.equals("Bond") || assetType.equals("Stock"))
            this.assetType = assetType;
        setPrice(price);
        id = id_counter;
        id_counter++;
    }

    public float getPrice() { return price; }
    public void setPrice(float price) {
        if(price >= 0) this.price = price;
    }
}

class Trader {
    String name;
    String department = "Bond";
    float aum = 0.0f;

    Trader(String name, String dept) {
        this.name = name;
        this.department = dept;
    }

    Trader(String name) { this.name = name; }

    public void assign(Asset asset) {
        if(asset.assetType != null && asset.assetType.equals(this.department)) {
            aum += asset.getPrice();
            asset.tradersName = this.name;
        } else {
            System.out.println("Department Mismatch");
        }
    }
}
